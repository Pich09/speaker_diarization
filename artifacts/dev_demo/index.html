Caveats

  • These are 10 dev meetings, not the 82-file test set; per-file DER is noisy.
  • The audio is simulated clean read speech, not real Khmer conversation.
  • Only the segmentation model was fine-tuned; embedding and PLDA are unchanged.
  • Speaker labels in predictions are clusters, not real identities; the mapping is arbitrary.
  • Exact solo stems work only for these synthetic meetings, where the simulator kept the source cuts separate; arbitrary real audio needs a separator and may leak artifacts.
