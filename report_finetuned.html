Gate decision

PASS: 4.62% vs 9.58%. The 1.0-point gate was met with a 4.96-point improvement. This is evidence for a larger pilot, not a production claim: the corpus is simulated clean read speech and only the segmentation model was adapted.

Caveats

  • Simulated clean read-speech, not real Khmer conversation; domain transfer is still unproven.
  • Only 16-17 speakers per split; a small set of source speakers dominates the data.
  • Source-cut overlap remains: 39 train/test and 451 train/dev cuts.
  • Only the EEND segmentation model was adapted; embedding and PLDA remain domain-mismatched.
  • All 8 epochs completed; the best checkpoint (epoch 8) was selected by validation loss, not test DER.
